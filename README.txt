PLANNINGREPAS — VERSION PWA (iPhone / Android)

Contenu
- index.html : application
- manifest.webmanifest : installation sur écran d'accueil
- sw.js : fonctionnement hors connexion après la première ouverture
- icon-192.png / icon-512.png : icônes

IMPORTANT
Sur iPhone, une PWA installable doit être servie par un site HTTPS.
Il ne suffit pas d'envoyer index.html par WhatsApp ou mail puis de l'ouvrir localement.

Installation sur iPhone une fois le site publié :
1. Ouvrir le lien dans Safari.
2. Toucher Partager.
3. Choisir « Sur l'écran d'accueil ».
4. Valider « Ajouter ».

Les cases cochées des listes de courses sont mémorisées localement sur chaque appareil.
